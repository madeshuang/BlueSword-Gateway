# 剩余数量与补货

网页显示的剩余数量，是系统根据取物任务维护的记录。这些数字不能代替现场清点，工作人员仍需核对实物。预留库存、可用数量与新任务限制的区别见[项目术语说明](../GLOSSARY.md)。

## 取物后，数量怎么变

假设当前还有 3 瓶水，访客确认取 2 瓶后，系统会先为这一单“预留” 2 瓶，网页显示的可用数量变成 1 瓶，避免把同一批水重复分给别人。

| 后续情况 | 数量如何处理 |
| --- | --- |
| 机器人明确拒绝任务 | 如期间没有重置该物品，退回这 2 瓶，可用数量恢复为 3 瓶；补货重置过的物品不再加回旧预留。 |
| 机器人通知取物完成 | 可用数量仍为 1 瓶，不会再扣一次。 |
| 机器人发生故障，或无法确认机器人是否接单 | 不自动退回数量，因为物品可能已经被取走，需要工作人员到现场核对。 |

每单最多两件，可以取同种两件或两种各一件。两种物品一起核查库存、一起预留；任一种缺货时整单不发，另一种也不单独扣减。AI 推荐、手动选择和最终提交都受当前可用数量及每单上限限制。物品取完后，须补货并重置数量，才能继续选择。

重启服务、点击“开始新体验”或“解除新任务限制”，都不会恢复库存。

## 补货后，怎么恢复数量

1. 打开网关地址的 `/#operations` 工作人员页面，在“补货重置”中选择已补货的物品。
2. 核对页面显示的补满目标，确认实物已经补满。本机人工练习时，可以模拟这一步。
3. 输入工作人员凭据，勾选补货确认，再点击重置按钮。系统会将所选物品恢复到补满目标，保留任务记录。

只有全部物品都已补满时，才选择“全部物品”并勾选全部补货确认。只补了一种物品，就只重置那一种。

等待机器人回复是否接单、等待结果或有告警时，仍可核对实物后重置库存。补货只更新数量，不结束原任务，也不解除网关接收新任务的限制。解除新任务限制同样不会补回数量。

例如，两种物品原来各有1件，确认各取1件后均为0。工作人员只把扑克牌补满到10，圆珠笔未补货仍为0；旧任务随后被拒绝，扑克牌保持10，圆珠笔退回1。若两种都补满到10，拒绝后都保持10。完成或故障通知也不再次扣减或退回。再次核对旧请求及重启均保留这些结果。

重置成功后，凭据和补货勾选会清空，下次操作需要重新填写和确认。本机操作见[本机人工联调指南](本机人工联调指南.md#无法继续取物时)，现场操作见[真实机器人联调指南](真实机器人联调指南.md#43-补货后更新页面库存)。
