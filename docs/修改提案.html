HONESTY关于“执行中的思考”

技能不是为了掩盖“大模型没在想”，而是真实机器人系统的分工方式。我们只展示真实生成的思考。

分

大模型负责判断，机器人程序负责动手

理解需求、选哪一样、先做什么、出了问题怎么解释，交给大模型；导航、对准、抓取需要毫秒级反馈和严格的安全检查，交给确定性的 GDK 程序。让大模型逐步“想”手臂怎么动，又慢又不安全。

实

执行期间，大模型确实在等待；所以我们不伪造

思考链里的每一个字都是模型实时生成的（只做中文代号翻译等显示清理，原文保留可查）。机器人的执行进度单独显示在右侧“执行记录”，不冒充为“思考”。

+

想在执行中也有思考：靠更多真实信息，而不是编

等级二之后，每条回报都可以交给大模型真实地“观察→思考”一两句（如“识别置信度 0.98，偏出可达范围，机器人在横移重新对准，这一步正常”）；等级四之后它看着画面想；展会后再把技能拆得更细，让模型在每一步之间真正做决策。

SAFETY兼容与安全

向后兼容

新字段、新接口全部可选。v1.1 网关 + v1.2 机器人、v1.2 网关 + v1.1 机器人都能互通，可以一个阶段一个阶段地加。

回报不阻塞控制

回报在后台线程异步发送、超时 1 秒、失败直接丢弃，不重试、不等回复。网关挂了，机器人照样把活干完。

动作前确认

无论 AI 推荐还是观众点名，机器人动之前都请观众确认；拒绝或超时，机器人不动，AI 如实告知。

AI 不碰运动参数

大模型只能选择技能和清单内物品；结果以机器人回报为准，AI 不能自行宣称完成。

不自动重发

无法确认是否接单时，不重发、锁定新任务，等工作人员核对（沿用网关 v1.1 的规则）。

取消接口（建议）

v1.1 没有取消接口，网关“停止任务”只能停止跟踪。建议可选新增 POST /api/task/cancel {taskId}。

INTEGRATION机器人侧接入示例（等级二起）

一个回报器 + 在已有流程里加几行。C++ 程序同理，用任意 HTTP 客户端在独立线程发送即可。

class Reporter:
    """异步回报；网关不可达时直接丢弃，绝不阻塞运动控制。"""
    def __init__(self, base_url):
        self.base = base_url.rstrip("/"); self.q = queue.Queue(maxsize=100)
        threading.Thread(target=self._run, daemon=True).start()
    def progress(self, task_id, stage, status, **extra):
        try: self.q.put_nowait(("/api/task/progress", {"taskId": task_id, "stage": stage, "status": status, **extra}))
        except queue.Full: pass
    def _run(self):
        while True:
            path, body = self.q.get()
            try: urllib.request.urlopen(urllib.request.Request(self.base + path, json.dumps(body).encode(),
                                                {"Content-Type": "application/json"}), timeout=1)
            except Exception: pass   # 回报失败不影响任务

reporter = Reporter("http://<网关IP>:4100")
navigate_to(location)                                   # 原有代码
reporter.progress(task_id, "navigate_to_shelf", "done", item=item, detail=f"停靠误差 {err:.1f} cm")
objects, target = detect(item)                          # 原有代码
reporter.progress(task_id, "detect", "done", item=item)
grasp(target)                                           # 原有代码
reporter.progress(task_id, "grasp", "done", item=item, detail="已确认稳定持物")
navigate_to_delivery(); reporter.progress(task_id, "navigate_to_delivery", "done")
place();                reporter.progress(task_id, "place", "done")
